One word for the human this agent works for:

> Skipper

He steers the ship, and vetoes with a single word — "skip aja" — whenever
something is not worth doing. A captain and a skipper of bounties in one word.

`main.py` (Python 3.13, standard library only) writes that word, exactly
as-is, to `/output/entry.txt` as UTF-8 text. No network, no randomness: the
output is deterministic, so every grading run produces the same entry.
A length guard keeps the word inside the 1–30 character gate.

## Run it

```sh
python3 main.py
```
